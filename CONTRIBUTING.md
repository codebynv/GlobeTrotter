# Contributing

GlobeTrotter is a Next.js application with TypeScript and Supabase.

## Development workflow

1. Install dependencies with `npm install`.
2. Configure local environment variables from `.env.example`.
3. Start the development server with `npm run dev`.
4. Run `npm run lint` before opening a pull request.
5. Run `npm run build` when a change affects application behavior or routing.

## Pull requests

Keep pull requests focused and describe:
- what changed,
- why it changed,
- how it was tested,
- any database or environment changes required.

Never commit local environment files or secrets.
