# Trip Sharing QA

- [ ] Owner can view and edit their trip.
- [ ] Authorized collaborator can access the shared trip.
- [ ] Uninvited user cannot access private trip details.
- [ ] Revoked collaborator loses access.
- [ ] Shared links do not expose unrelated trips.
- [ ] Permission checks are enforced by the backend.

Test both successful access and denied access before shipping sharing changes.
