# Smoke Test Plan

Run this checklist after changes to trip creation, editing, search, or navigation.

- Create a trip with valid required fields.
- Open the trip and verify the saved values.
- Edit a field and confirm the change persists after refresh.
- Try an empty required field and confirm submission is blocked clearly.
- Open a trip that does not exist and verify a safe not-found state.
- Test the main flow at a narrow viewport.

Record which checks were actually run for each release.
