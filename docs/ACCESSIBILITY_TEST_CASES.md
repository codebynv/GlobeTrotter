# Accessibility Test Cases

Use these cases during manual accessibility review.

- Navigate the trip form using only Tab, Shift+Tab, Enter, and Space.
- Confirm focus remains visible and follows a logical order.
- Submit an invalid form and confirm errors are announced and associated with fields.
- Check that icon-only controls have accessible names.
- Zoom to 200% and check for clipped content.
- Verify meaningful images have useful alternative text.
- Confirm status is not communicated by color alone.

Record browser, viewport, and any reproducible failures.
